# Employee_Onboarding
A Database source code in MySQL Workbench that manages all of the onboarding of a new employee. 


Define what “onboarding” means in your system
Most onboarding systems track:

1. Employee personal info
2. Job/role details
3. Required onboarding tasks (HR, IT, training, compliance)
4. Documents & acknowledgements
5. Equipment & access
6. Status and deadlines
7. Who is responsible for each step

This database can grow as your process grows.
